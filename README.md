# 🩺 Project Final - Family Doctor

A web application designed for family doctor management and medical appointment scheduling. It allows patients to book slots and doctors to manage their schedules efficiently.

### 🚀 Features
- User Authentication & Secure Login.
- Appointment booking and scheduling system.
- Doctor and Patient dashboard.
